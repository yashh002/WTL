# Marathwada Kalagram — Static Website

Pure HTML/CSS/JS. No server, database, or Node.js needed.

- **Shop:** "ऑर्डर करा" opens a chooser → WhatsApp (pre-filled product message) or phone call.
- **Registration:** the form builds a WhatsApp message with the person's details; there is also a Call button.
- **Number used:** +91 75176 47277 (change `917517647277` / `+917517647277` in index.html and shop.html to update).

## Deploy (free)
Upload this folder to Netlify (drag & drop), Cloudflare Pages, or GitHub Pages. Open `index.html` locally to preview.

Do NOT upload `.env`, `server.js`, `admin.html` or `node_modules` — they are no longer needed.
